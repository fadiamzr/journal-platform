# apps/api

This directory will contain the **Python 3.12 + FastAPI** backend.

| Phase | Scope |
|---|---|
| **Phase 4** | FastAPI core — app scaffold, JWKS JWT middleware, role guards, Docker Compose |
| **Phase 5** | AI extraction — LLM provider abstraction (`LLM_PROVIDER`), metadata extraction |
| **Phase 6** | Workflow & review API — submission lifecycle, reviewer assignment, decision endpoints |

Planned tech: FastAPI, Pydantic v2, Uvicorn, httpx, supabase-py, Docker.

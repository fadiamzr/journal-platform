# apps/web

This directory will contain the **Next.js 15 App Router** frontend.

| Phase | Scope |
|---|---|
| **Phase 7** | Frontend foundation — Next.js 15, next-intl (en/fr/ar + RTL), Supabase Auth, role-aware navigation |
| **Phase 8** | Author portal — submission wizard, revision upload, feedback view |
| **Phase 9** | Reviewer interface — assignment accept/decline, structured review form |
| **Phase 10** | Editor board — submission queue, reviewer assignment, decision workflow |
| **Phase 11** | Public reading — published article pages, issue archive, DOI resolution |

Planned tech: Next.js 15 (App Router), TypeScript, Tailwind CSS, Shadcn/ui, next-intl (en/fr/ar + RTL).
